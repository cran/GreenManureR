Analysing green manure decomposition, nutrient release and crop response

Overview

GreenManureR supports experiments in which a green manure or cover crop (Mucuna, sunhemp, dhaincha and others) is incorporated, its residues decompose in litterbags, nutrients are released, and one or more succeeding crops (for example kharif and rabi) respond. The package links these three stages:

  1. decomp_fit() and decomp_t50(): residue decomposition;
  2. nutrient_release(): N, P, K and other nutrient release;
  3. greenmanure_n_balance(): N inputs, crop uptake and apparent balance;
  4. carryover_effect(): residual effects on succeeding crops;
  5. gm_joint_analysis() and greenmanure_report(): integration and reporting.

The examples use simulated data (gm_litterbag, gm_agronomy) that mimic the structure of a real experiment.

Decomposition models

With \(M\) the percentage of initial mass remaining, three models are fitted per group and ranked by AICc:

  • single pool: \(M = 100\,e^{-kt}\);
  • double pool: \(M = 100\,[A e^{-k_f t} + (1-A) e^{-k_s t}]\) with \(k_s \le k_f\);
  • asymptotic: \(M = C + (100 - C) e^{-kt}\), where \(C\) is the recalcitrant residue.
fit <- decomp_fit(gm_litterbag, time = "time", mass = "mass", group = "treatment")
fit$table[fit$table$selected, c("treatment", "model", "k", "k_slow", "pool_A", "R2", "AICc")]
#>   treatment      model          k      k_slow    pool_A        R2     AICc
#> 2    Mucuna     double 0.05534686 0.003937137 0.5186680 0.9981959 105.0605
#> 6   Sunhemp asymptotic 0.03251040          NA        NA 0.9937364 133.4892
#> 8  Dhaincha     double 0.06455903 0.004476614 0.5539521 0.9971639 125.1666

The time to 50% mass loss uses the selected model, with a Monte-Carlo interval based on the covariance matrix of the nonlinear least squares fit:

decomp_t50(fit)
#>   treatment      model   p      t50      lwr      upr

Nutrient release

Nutrient remaining is mass x concentration / initial concentration, so values above 100% indicate net immobilization. Supplying the dry matter input (biomass, t/ha) also yields absolute release in kg/ha.

nr <- nutrient_release(gm_litterbag, nutrients = c("N", "P", "K"),
                       group = "treatment", biomass = "biomass_tha",
                       at = c(14, 30, 60))

ANR is the apparent N recovery from the green manure relative to the control at the same fertilizer N level. NFRV is the fertilizer N replacement value, obtained by inverting a quadratic response fitted to the control plots; it is NA when the yield lies outside the fitted range.

Residual effects on succeeding crops

The treatment x season term in the pooled analysis tests whether the green manure effect changes between crops; retention_vs_first gives the second-crop effect as a percentage of the first-crop effect.

Reporting

greenmanure_report() writes CSV tables, PNG figures and a Word report to a directory of your choice:

greenmanure_report(fit, nr, nb, co, ja, outdir = "gm_report")
